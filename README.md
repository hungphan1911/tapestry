# tapestry

As the name "Tapestry" suggests, it's a bunch of mostly unrelated services stitched together into one big, slightly chaotic picture, all built into a big repo to serve my personal needs :p.

The only real requirements are an unused old laptop to host the platform, plus Tailscale installed on both the host and any devices that plan to access it. What's also so cool is that Tailscale is free for personal use.

Relevant design decisions and system architecture are documented in the `docs/` directory.

## A little backstory

I came across this idea a while back while thinking about what projects I should build to show off on my GitHub. Then it hit me: we don't really need to think about projects that way.

Instead, why not just put everything together into one system and design it in a way that can scale easily? Eventually, it becomes a large enough project on its own, and along the way, you get to experiment a lot with system design, architecture, and how different pieces fit together :D.
